## 🧩 About

**Subnautica 2 desktop helper** is a curated list of Subnautica 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, biome map viewer
- **Quality-of-Life Helpers** — inventory organizer, crafting notes, overlay notes
- **Research Notes** — exploration routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Exploration Helpers
- Resource Tracker — highlight nearby materials for study
- Biome Map Notes — visualize explored regions
- Depth Gauge Overlay — read current depth at a glance
- Playback Notes — review dive routes in the editor

### 🎨 Inventory & Cosmetics
- Inventory Organizer — sort and label gathered items
- Crafting Notes — browse recipe trees and costs
- Base Layout Notes — plan habitat modules

### 🏋️ Survival Layout
- Oxygen Timer Notes — track remaining air during study runs
- Vehicle Status Overlay — monitor seamoth and prawn telemetry
- Waypoint Notes — chain navigation markers in the editor

| Parameter | Type | Default | Description |
